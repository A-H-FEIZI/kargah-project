## مصاحبه‌های جونیور در ایران واقعاً چه شکلی هستند؟

شرکت‌های بزرگ ایرانی در سطح جونیور/کارآموز این چیزها را آزمایش می‌کنند:

۱. **آیا منطقی فکر می‌کنی؟** — حل مسئله پایه، نه تسلط بر الگوریتم
۲. **آیا می‌فهمی وب چطور کار می‌کند؟** — HTTP، کلاینت-سرور، دیتابیس
۳. **می‌توانی درباره چیزی که ساختی صحبت کنی؟** — پروژه Kargah تو جواب اینجاست
۴. **آیا ارزش سرمایه‌گذاری داری؟** — کنجکاوی، صداقت، توانایی یادگیری

آن‌ها **به دنبال ۱۰ سال تجربه نیستند.** آن‌ها **به دنبال کسی هستند که چیزی واقعی ساخته و می‌تواند آن را واضح توضیح دهد.**

## بخش ۱: سوالات فنی

### مبانی علوم کامپیوتر

**س: تفاوت زبان کامپایلری و تفسیری چیست؟**
ج: زبان‌های کامپایلری (مثل C) قبل از اجرا به طور کامل ترجمه می‌شوند. زبان‌های تفسیری (مثل Python) خط به خط هنگام اجرا ترجمه می‌شوند. Python تفسیری است — به همین دلیل می‌توانید یک اسکریپت Python را مستقیماً بدون مرحله build جداگانه اجرا کنید.

**س: RAM در مقابل ذخیره‌سازی چیست؟**
ج: RAM حافظه موقت سریع است — وقتی کامپیوتر خاموش می‌شود از بین می‌رود. ذخیره‌سازی (هارد دیسک/SSD) دائمی است. برنامه‌ها در RAM اجرا می‌شوند؛ فایل‌ها در ذخیره‌سازی ذخیره می‌شوند.

**س: سیستم‌عامل چیست؟**
ج: نرم‌افزاری که منابع سخت‌افزاری (CPU، RAM، ذخیره‌سازی) را مدیریت می‌کند و اجازه می‌دهد برنامه‌های دیگر اجرا شوند. ویندوز، لینوکس و macOS سیستم‌عامل هستند.

---

### شبکه (حوزه قوی او — برای درخشیدن آماده شو)

**س: آدرس IP چیست؟**
ج: یک آدرس منحصربه‌فرد که یک دستگاه را در شبکه شناسایی می‌کند، مثل آدرس خانه برای کامپیوترها.

**س: DNS چیست؟**
ج: سیستم نام دامنه — نام‌های دامنه خواندنی برای انسان (مثل google.com) را به آدرس‌های IP که کامپیوترها برای اتصال استفاده می‌کنند ترجمه می‌کند.

**س: HTTP چیست؟ HTTPS چیست؟**
ج: HTTP پروتکلی است که مرورگرها برای ارتباط با سرورها استفاده می‌کنند. HTTPS نسخه امن است — تمام داده‌ها رمزگذاری می‌شوند. وقتی قفل را در مرورگر می‌بینید، آن HTTPS است.

**س: تفاوت TCP و UDP چیست؟**
ج: TCP تحویل را تضمین می‌کند (مثل پست سفارشی — می‌دانید رسیده). UDP سریع‌تر است اما تحویل را تضمین نمی‌کند (مثل پخش رادیویی). مرور وب از TCP استفاده می‌کند؛ پخش ویدیو گاهی از UDP.

---

### توسعه وب

**س: وقتی یک URL در مرورگر تایپ می‌کنید چه اتفاقی می‌افتد؟**
ج کامل:
۱. مرورگر از DNS می‌خواهد دامنه را به IP ترجمه کند
۲. مرورگر یک درخواست HTTP GET به آن آدرس IP ارسال می‌کند
۳. سرور درخواست را دریافت می‌کند و HTML/CSS/JS برمی‌گرداند
۴. مرورگر HTML را به یک صفحه قابل مشاهده رندر می‌کند

**س: REST API چیست؟**
ج: API (رابط برنامه‌نویسی اپلیکیشن) روشی است که برنامه‌ها با یکدیگر صحبت می‌کنند. REST مجموعه‌ای از قوانین برای طراحی API های وب است. یک REST API از متدهای HTTP استفاده می‌کند: GET برای خواندن، POST برای ایجاد، PUT/PATCH برای به‌روزرسانی، DELETE برای حذف.

**س: تفاوت GET و POST چیست؟**
ج: GET داده دریافت می‌کند (مثل جستجو). POST داده ارسال می‌کند تا چیزی ایجاد کند (مثل ارسال فرم). پارامترهای GET در URL قابل مشاهده هستند؛ داده‌های POST در body درخواست هستند.

**س: JSON چیست؟**
ج: JavaScript Object Notation — یک فرمت متنی برای ارسال داده‌های ساختاریافته بین سرور و مرورگر. اینگونه به نظر می‌رسد: `{"name": "علی", "craft": "سفال"}`

**س: تفاوت فرانت‌اند و بک‌اند چیست؟**
ج: فرانت‌اند همه چیزی است که کاربر می‌بیند و با آن تعامل می‌کند — HTML، CSS، JavaScript در مرورگر. بک‌اند منطق سمت سرور است — پردازش درخواست‌ها، صحبت با دیتابیس، بازگرداندن داده. در Kargah، صفحه لیست صنعتگران فرانت‌اند است؛ endpoint /artisans بک‌اند است.

---

### دیتابیس

**س: دیتابیس چیست؟**
ج: مجموعه‌ای سازمان‌یافته از داده‌ها که به گونه‌ای ذخیره شده که به راحتی قابل دسترسی و اصلاح باشد. مثل یک صفحه‌گسترده بسیار قدرتمند و ساختاریافته.

**س: SQL چیست؟**
ج: زبان کوئری ساختاریافته — زبانی که برای تعامل با دیتابیس‌های رابطه‌ای استفاده می‌شود. SELECT، INSERT، UPDATE، DELETE دستورات اصلی هستند.

**س: کلید اصلی (Primary Key) چیست؟**
ج: یک شناسه منحصربه‌فرد برای هر ردیف در یک جدول دیتابیس. مثل یک شماره ID — هیچ دو ردیفی نمی‌توانند کلید اصلی یکسانی داشته باشند.

**س: کلید خارجی (Foreign Key) چیست؟**
ج: یک ستون در یک جدول که به کلید اصلی جدول دیگری اشاره می‌کند و رابطه‌ای بین آن‌ها ایجاد می‌کند. در Kargah، یک رکورد صنعتگر یک category_id دارد که به جدول categories اشاره می‌کند.

### اصول Python

**س: تفاوت list و dictionary در Python چیست؟**
ج: list یک مجموعه مرتب است که با index دسترسی دارد: `["علی", "رضا", "سارا"]`. dictionary جفت‌های key-value ذخیره می‌کند که با key دسترسی دارند: `{"name": "علی", "city": "اصفهان"}`.

**تمرین — این‌ها را از حافظه بنویس:**
```python
# یک تابع بنویس که طولانی‌ترین کلمه را در یک لیست برگرداند
def longest_word(words):
    return max(words, key=len)

# یک تابع بنویس که تعداد دفعات ظاهر شدن هر کلمه را بشمارد
def word_count(sentence):
    words = sentence.split()
    counts = {}
    for word in words:
        counts[word] = counts.get(word, 0) + 1
    return counts
```

## بخش ۲: سوالات رفتاری (روش STAR)

**STAR = وضعیت (Situation)، وظیفه (Task)، اقدام (Action)، نتیجه (Result)**

هر پاسخ رفتاری باید این ساختار را در ۶۰ تا ۹۰ ثانیه دنبال کند.

---

**س: خودت را معرفی کن.**
قالب: "دانشجوی مهندسی کامپیوتر دانشگاه آزاد هستم. در ۳ ماه گذشته یک پلتفرم وب به نام Kargah برای کشف صنعتگران سنتی ایرانی ساختم. قبل از این، ۶ ماه به عنوان تکنسین شبکه کار کردم که به من درک قوی از نحوه کار زیرساخت داد. به خصوص به [توسعه بک‌اند / فرانت‌اند / هر مسیری که انتخاب کرد] علاقه دارم و به دنبال محیطی هستم که بتوانم به سرعت یاد بگیرم."

---

**س: درباره پروژه‌ای که ساختی بگو.**
قالب: "Kargah ساختم — یک پلتفرم برای کشف صنعتگران سنتی ایرانی. بک‌اند FastAPI دارد، دیتابیس SQLite و فرانت‌اند JavaScript. کاربران می‌توانند صنعتگران را بر اساس دسته‌بندی مرور کنند، بر اساس شهر جستجو کنند و پروفایل‌های پورتفولیو را ببینند. یک پنل ادمین به مالک اجازه می‌دهد لیست صنعتگران را اضافه و مدیریت کند. در ۳ ماه ساختمش، از صفر دانش کدنویسی شروع کردم و تمام مدت از Git استفاده کردم تا هر قدم را در تاریخچه commit ببینید."

---

**س: سخت‌ترین مشکل فنی که حل کردی چه بود؟**
به آن لحظه خاص در Kargah فکر کن که چیزی واقعاً خراب بود و تو آن را درست کردی. مشکل دقیق، آنچه امتحان کردی و آنچه کار کرد را نام ببر.

---

**س: وقتی گیر می‌کنی چه کار می‌کنی؟**
پاسخ خوب: "اول پیام خطا را با دقت دوباره می‌خوانم — اکثر خطاها توضیح می‌دهند چه اشتباهی شده. بعد Stack Overflow را با متن دقیق خطا جستجو می‌کنم. اگر بعد از ۳۰ دقیقه هنوز گیر کردم با منتورم تماس می‌گیرم. یاد گرفتم که ساعت‌ها تنها گیر کردن کمتر از یک مکالمه ۵ دقیقه‌ای با کسی که جواب را می‌داند مفید است."

---

**س: نقطه ضعف اصلی‌ات چیست؟**
چیز واقعی اما بی‌خطر انتخاب کن و همیشه با آنچه درباره‌اش داری می‌کنی ادامه بده.
مثال: "هنوز در خواندن مستندات انگلیسی آهسته هستم، بنابراین گاهی وظایف بیشتر از حد معمول طول می‌کشند. به طور عمدی مستندات انگلیسی می‌خوانم به جای اینکه همیشه به منابع فارسی سوئیچ کنم، و دارد سریع‌تر می‌شود."

## بخش ۳: اسکریپت دمو Kargah

وقتی از او خواسته می‌شود پروژه‌اش را دمو کند (۵ تا ۱۰ دقیقه):

۱. **(۱ دقیقه) زمینه** — "Kargah یک پلتفرم کشف برای صنعتگران سنتی ایرانی است. مشکلی که حل می‌کند این است که میلیون‌ها هنرمند ایرانی حضور دیجیتال ندارند."

۲. **(۱ دقیقه) نمای کلی معماری** — یک نمودار ساده رسم یا نشان بده: مرورگر ← فرانت‌اند JavaScript ← بک‌اند FastAPI ← دیتابیس SQLite

۳. **(۳ دقیقه) دمو زنده** — مرور دسته‌بندی‌ها ← کلیک روی یک صنعتگر ← نشان دادن پروفایل ← نشان دادن کار جستجو ← نشان دادن ورود ادمین ← افزودن یک صنعتگر جدید

۴. **(۲ دقیقه) بازبینی کد** — VS Code را باز کن. endpoint FastAPI را که لیست صنعتگران را پشتیبانی می‌کند نشان بده. schema دیتابیس را نشان بده. یک Git commit را نشان بده و توضیح بده چه چیزی تغییر کرد.

۵. **(۱ دقیقه) اگر وقت بیشتری داشتم** — "اگر یک ماه دیگر داشتم، یک سیستم نظرات اضافه می‌کردم و به یکپارچه‌سازی درگاه پرداخت برای درخواست‌های رزرو نگاه می‌کردم."

## بخش ۴: یادداشت‌های خاص شرکت

| شرکت | حوزه تمرکز | نکته |
|---|---|---|
| **اسنپ** | پلتفرم ride-hailing، بک‌اند مقیاس بالا | به مقیاس و قابلیت اطمینان اهمیت می‌دهند. ذکر کن که می‌دانی یک endpoint که به میلیون‌ها درخواست سرویس می‌دهد به caching و بهینه‌سازی نیاز دارد. |
| **دیجی‌کالا** | تجارت الکترونیک، کاتالوگ بزرگ | آن‌ها بر اساس محصولات، SKU، موجودی فکر می‌کنند. پروفایل‌های صنعتگر Kargah مثل لیست محصولات هستند — این تشابه را بکش. |
| **کافه‌بازار** | فروشگاه برنامه، کاربر بزرگ | به تفکر محصولی ارزش می‌دهند. ذکر کن که یک PRD برای یک ویژگی Kargah نوشتی. |
| **دیوار** | آگهی‌های رده‌بندی‌شده، جستجو محور | هسته آن‌ها جستجو و فیلتر است — دقیقاً همان چیزی که در Kargah ساختی. |
| **تپسی** | ride-hailing | مشابه اسنپ. قابلیت اطمینان بک‌اند، API های تمیز. |
| **بلد** | نقشه و کشف محلی | مرتبط‌ترین به Kargah. کشف محلی هسته آن‌هاست. |
