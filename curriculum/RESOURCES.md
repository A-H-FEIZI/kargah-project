## Week-by-Week Resource Map

### Week 1 — Technology Landscape & Setup

**Persian:**
- [مکتب‌خونه — مقدمه‌ای بر مهندسی نرم‌افزار](https://maktabkhooneh.org) — search "مقدمه برنامه نویسی"
- [فرادرس — شبکه‌های کامپیوتری](https://faradars.org) — connects well to his network background
- [آپارات — چطور اینترنت کار می‌کند](https://aparat.com) — search "نحوه کار اینترنت"

**English:**
- [CS50 Week 0 — Harvard](https://cs50.harvard.edu/x/) — best free intro to CS in the world. Watch with Persian subtitles if available.
- [How the Internet Works — Mozilla](https://developer.mozilla.org/en-US/docs/Learn/Common_questions/Web_mechanics/How_does_the_Internet_work)

**Setup Guides:**
- VS Code download: https://code.visualstudio.com/
- Git download: https://git-scm.com/
- WSL setup (Microsoft official): search "Install WSL Windows"

### Week 2 — Terminal & Git

**Persian:**

- [فرادرس — آموزش گیت و گیت‌هاب](https://faradars.org) — search "git"

### Week 3 — Python Basics
