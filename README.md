## Quick Summary

**Student:** Computer engineering student, 5th semester, Azad University (online)
**Starting Level:** Zero coding experience
**Weekly Budget:** 25–30 hours
**Duration:** 12 weeks (3 months) + 2-week buffer
**Output:** Working Kargah MVP + interview readiness + clear career path

**The Product — Kargah:**
An online discovery platform connecting people with Iran's traditional artisans and craftspeople (carpet weavers, pottery makers, calligraphers, miniature artists). Built with Python (FastAPI) + SQLite + HTML/CSS/JavaScript. Runs entirely on a laptop — no cloud needed.

**Target Interview Companies:** Snapp, Digikala, Cafe Bazaar, Divar, Tapsi, Balad

## The 3-Month Arc

```
Month 1 (Weeks 1–4)   Foundations      Terminal, Git, Python, HTML/CSS
Month 2 (Weeks 5–8)   Building Blocks  JavaScript, FastAPI, SQLite, Full Stack
Month 3 (Weeks 9–12)  Product Sprint   Build Kargah MVP + Soft Skills + Interview Prep
```
