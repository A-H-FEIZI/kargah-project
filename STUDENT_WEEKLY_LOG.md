## Reflection Guide — End of Each Month

### Month 1 Reflection (after Week 4)

Answer these honestly:

1. Which week's topic would you want to spend another week on?
2. Which week's topic was the most boring?
3. When you explained what you built to someone (a friend, family member), what part were you most excited to describe?
4. If you had to do one of these things every day for a year, which would you choose: design how a page looks (CSS), make a page interactive (JS), or write Python scripts?

---

### Month 2 Reflection (after Week 8)

Answer these honestly:

1. Backend (building APIs, database logic) vs Frontend (making pages look and work well) — which felt more natural?
2. Did the database design week excite you or bore you?
3. When the full-stack mini-app connected for the first time, how did that feel?
4. If Kargah were a real company with 5 engineers, which role would you want? (Frontend, Backend, DevOps, Data, Product Manager)

---

### Month 3 Final Reflection (after Week 12)

This is the most important one. Set aside 1 hour for it.

1. Looking at all 12 weekly logs — which path appeared most in the "flow state" column?
2. Looking at all 12 weekly logs — which path appeared most in the "dreaded opening the laptop" column?
3. What is the one thing you built that you're genuinely proud of?
4. What is one thing about your code that you know is bad and you'd fix if you had another week?
5. If you had to describe your learning journey to a hiring manager in 2 minutes, what would you say?
6. What is your primary path going forward?
7. What specific skill do you want to develop in the next 3 months?
